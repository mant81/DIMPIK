# DIMPIK 보안 점검 및 개선 — 2026-10-31

대상: 현재 저장소의 Windows x64 소스·로컬 빌드. 원격 침투 테스트나 보안 인증은 아닙니다. 점검 시점에는 GitHub 릴리즈를 교체하지 않았습니다. 1.0.1 배포 정보는 [RELEASE_1.0.1.md](RELEASE_1.0.1.md)를 참고하세요.

## 적용한 개선

### 캡처 세션 보호

- 원본·주석·실행 취소 이력을 포함한 세션 전체를 Windows DPAPI의 **CurrentUser** 범위로 암호화합니다. 키나 비밀번호를 프로그램에 저장하지 않습니다.
- 기존 `session.json` 파일명은 유지하지만 새 내용은 버전 헤더와 암호문입니다. 임시 파일에도 암호문만 기록하고 디스크 flush 후 교체합니다. 저장 실패 시 이전 파일을 유지하며 새 임시 파일을 정리합니다.
- 이전 평문 JSON은 구조·값·이미지를 검증하고 복원에 성공한 뒤 같은 경로에 암호화하여 교체합니다. 검증에 실패한 파일은 자동 덮어쓰기하지 않습니다.
- 손상되거나 현재 Windows 계정으로 복호화할 수 없는 세션은 거부합니다. 캡처를 위해 숨겨진 상태로 시작했더라도 오류가 발생하면 편집 창과 오류 상태를 표시하여 숨겨진 채 멈추지 않도록 했습니다.
- 편집 복원과 Undo 기능은 유지합니다. DPAPI는 같은 사용자 계정의 프로그램이나 해당 계정이 장악된 상황까지 막지 못합니다. 다른 PC/계정으로 파일을 복사하면 복원되지 않을 수 있습니다. 별도 계정 간 복호화 거부는 이번 환경에서 실기 검증하지 않았습니다.

### 변조·대용량 데이터 제한

- 세션의 JSON 크기 128MiB, 탭 128개, 문서별 주석 2,048개, Undo 256개, 전체 주석 50,000개, 전체 이미지 픽셀 예산 128,000,000을 검사합니다. JSON 중첩 깊이는 32로 제한합니다.
- 목록의 크기와 형식을 먼저 검사한 뒤 문서 객체로 변환합니다. 주석 종류, 유한한 좌표·크기·확대율, 이름, 스크롤 및 저장 경로 형식을 검증합니다.
- PNG/JPEG/BMP 파일은 64MiB, 한 이미지 64,000,000픽셀, 한 변 32,768픽셀로 제한합니다. GDI+ 디코더를 호출하기 전에 형식별 헤더의 크기를 검사합니다. JPEG의 크기 정보가 첫 1MiB 내에 없으면 거부합니다.
- 이미지 열기, 세션 이미지, 이미지 주석 및 클립보드 이미지의 추가 처리를 제한합니다. OS 클립보드에서 이미지를 받는 초기 단계는 Windows API가 처리하므로 모든 디코딩 자원 사용을 사전에 제한한다고 보장하지는 않습니다.
- 설정 파일은 1MiB로 제한하며 이전 설정 복사도 크기를 확인합니다.
- 제한을 넘는 편집 상태는 저장 오류를 표시하고 창을 유지합니다. 사용자가 저장한 PNG나 편집 작업을 자동 삭제하지 않습니다. 완전한 미디어 퍼징이나 모든 메모리 고갈 상황을 방어한다는 의미는 아닙니다.

### 네이티브 보호

- 고정 버퍼의 모든 문자열 복사·추가에 경계 검사를 적용했습니다. 경로 API의 실패·잘림도 검사하며 긴 경로는 오류 코드 111로 거부합니다. 이는 로컬 실행 환경을 제어해야 발생하는 메모리 손상 위험이며, 원격 실행·권한 상승을 입증한 것은 아닙니다.
- 실제 인자를 분리해 정확히 비교하여 경로나 미지원 옵션에 포함된 문자열로 로그인 자동 실행이 등록되는 오인식을 막았습니다.
- DLL 기본 검색에서 현재 작업 폴더와 PATH를 제외했습니다. 이 변경 이전에 이미 로드된 DLL이나 .NET 편집기의 모든 로딩 동작에 대한 보증은 아닙니다.
- 사용자 지정 CRT 진입점과 `/GS-`를 제거했습니다. 정적 CRT의 표준 진입점을 사용해 보안 쿠키를 초기화하고 `/GS`, `/sdl`, CFG, ASLR, High Entropy VA, DEP 및 CET 호환 플래그를 적용했습니다. 실제 적용되는 완화 기능은 OS와 하드웨어에도 의존합니다.
- dumpbin에서 비어 있지 않은 Security Cookie, CFG 체크·디스패치 포인터와 함수 테이블, CF instrumented 및 CET compatible 표시를 확인했습니다. 트레이 실행 파일 크기는 120,320바이트입니다.
- `.gitignore`에 인증서 개인 키 및 로컬 `.env` 파일 제외 규칙을 추가했습니다. 이미 추적되거나 외부에 공유된 파일에는 소급 적용되지 않습니다.

## 실제 검증

환경: Windows x64, .NET SDK 10.0.403 / 배포 런타임 10.0.14, MSVC, Inno Setup.

앱 게시 성공 후 설치 파일 생성에서 한 차례 EndUpdateResource(110) 오류가 발생했습니다. 보안 설정 변경 없이 별도 출력 폴더에서 Inno Setup 컴파일에 성공했고, 정식 경로 `release\setup\dimpik_inst_x64_1.0.0.exe`로 복사했습니다. 별도 smoke 설치 패키지도 생성·검증했습니다.

앞선 NuGet 전이 의존성 검사에서 알려진 취약 패키지는 없었으며 이번 변경으로 외부 PackageReference를 추가하지 않았습니다. 앞선 소스의 일반적인 개인 키·AWS/GitHub 키 패턴 검사에서도 일치 파일을 발견하지 못했습니다. OS·프레임워크·모든 비밀 형식·Git 전체 이력을 포괄한 결과는 아닙니다.

앱 소스에서 캡처를 외부로 보내는 HTTP/소켓 코드는 발견하지 못했습니다. OS 클립보드 동기화, 사용자가 선택한 네트워크 저장 폴더와 기존 원본 자동 저장은 별도입니다. 설치는 관리자 권한으로 Program Files에 수행하고 이후 앱은 원래 사용자 권한으로 실행합니다. 사용자 계정 간 설치 ACL 공격 실험은 미실시입니다.

## 남은 사항

1. **미서명 배포:** 공인 코드 서명 인증서가 없어 앱과 설치 파일은 미서명입니다. SmartScreen 경고 문제는 남아 있습니다.
2. **백신 검사 미완료:** Microsoft Defender는 AntivirusEnabled=False, RealTimeProtectionEnabled=False로 확인되었습니다. 보안 설정은 변경하지 않았으며 악성코드 검사를 통과했다고 주장할 수 없습니다. 다른 백신 상태도 확인하지 못했습니다.
3. **대기 메모리:** 약 11MB로 목표를 초과합니다. 암호화 세션 동작은 별도 검사를 통과했지만 메모리 목표는 아직 충족하지 못했습니다.
4. **보호 범위:** 실행 중 메모리, OS 클립보드, 별도 저장 PNG, 이전 버전의 평문 백업·삭제 영역·다른 복사본은 세션 암호화로 보호되지 않습니다. 파일 삭제는 보안 삭제가 아닙니다. 민감 원본과 Undo가 필요 없으면 트레이 종료로 보관 세션을 지우고 편집한 PNG만 공유하세요.
