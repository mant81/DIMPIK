# DIMPIK 1.0.1 — 버그 수정 및 보안 개선

### 버그 수정

- 트레이 대기 중 캡처할 때 편집 창이 잠깐 나타나던 문제를 수정했습니다. 캡처 전에는 창을 숨기고 완료 후 결과를 표시합니다.
- 영역 선택을 취소하면 편집 창을 열지 않고 트레이 대기로 돌아갑니다.
- 설치 완료 후 실행 체크박스 없이 트레이에서 자동 실행합니다.
- 설치 시 Windows 로그인 자동 실행을 기본 체크로 제공합니다. 사용자는 설치 화면이나 설정에서 해제할 수 있습니다.

### 보안 개선

- 원본·주석·실행 취소 이력을 포함한 보관 세션을 현재 Windows 계정으로 암호화합니다. 이전 평문 세션은 검증 후 자동 변환합니다.
- 손상된 세션과 잘못된 값·과도한 크기의 이미지/설정/편집 데이터를 거부하도록 검증을 강화했습니다.
- 네이티브 트레이의 긴 경로 버퍼 처리와 명령행 해석을 수정하고 스택 보호·CFG·DLL 검색 경로 보호를 적용했습니다.

### 설치 및 참고

- Windows 10/11 x64 · 개인·기업·관공서 무료 · 제작사 AAStudio.kr.
- 기존 DIMPIK를 트레이에서 종료한 뒤 설치하세요. 필요한 결과는 먼저 PNG로 저장하세요.
- 암호화된 세션은 다른 Windows 계정/PC에서 복원되지 않을 수 있습니다. 같은 계정 권한의 프로그램, 클립보드 및 별도 저장한 PNG까지 보호하지는 않습니다.
- 공인 코드 서명은 미적용이며 SmartScreen 경고가 나타날 수 있습니다. 백신 검사는 완료하지 못했습니다.
- 현재 환경의 트레이 대기 메모리는 약 11MB로 10MB 목표를 초과합니다.

[1.0.1 설치 파일](https://github.com/mant81/ASnapdo/releases/download/v1.0.1/asnapdo_inst_x64_1.0.1.exe)


### 검증

Windows에서 보안 회귀 검사, 전체 DIMPIK.Smoke, 캡처 시작 검사, 암호화 세션 복원/종료 검사와 긴 경로 검사를 통과했습니다. 별도 AppId의 설치·재설치·제거 및 기본 로그인 자동 실행 등록 검사도 통과했습니다. 트레이·편집기·설치 파일의 실제 파일 버전이 모두 1.0.1임을 확인했습니다. 실제 Windows 재로그인과 다른 관리자 계정을 입력하는 UAC 설치는 실기 검증하지 않았습니다.
