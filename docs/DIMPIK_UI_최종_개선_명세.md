# DIMPIK (딤픽) — 최종 UI·UX 개선 명세

> 문서 버전: 1.0  
> 작성일: 2026-11-08  
> 대상: 기존 캡쳐·편집 프로그램을 **DIMPIK**으로 개선  
> 플랫폼: Windows 전용 / Microsoft Store 및 GitHub 배포  
> 라이선스 방향: MIT 오픈소스

## 1. 목적과 확정 원칙

DIMPIK은 Windows에서 화면을 빠르게 캡쳐하고, 여러 캡쳐를 **탭으로 계속 누적**하며, 텍스트·화살표·도형·번호·형광펜·모자이크·블러 등의 주석 작업을 수행하는 앱이다.

- **독창적인 UI**: 알캡처·그림판·PicPick의 화면 배치를 복제하지 않는다. 참고하는 것은 사용성 패턴(창 크기에 따른 축약, 도구 팝업)뿐이다.
- **캔버스 우선**: 캡쳐 이미지 양옆에 고정 도구 패널이나 속성 패널을 두지 않는다.
- **상단 기본 배치**: 상단에 기본 작업 명령과 편집 도구를 배치하고, **그 아래 탭**, 그 아래 캔버스를 둔다.
- **선택 가능한 도구 위치**: 사용자는 **상단형 / 좌측형** 도구 모음 중 하나를 선택할 수 있다. 기본값은 상단형. 두 모음을 동시에 보여주지 않는다.
- **도구 내부 설정**: 별도의 속성 바/고정 속성 패널 대신, 도구 버튼의 ▼를 누르면 **해당 도구에 붙은 팝업(Flyout)**이 뜬다. 팝업은 화면 배치를 밀어내지 않는다.
- **탭 누적**: 새 캡쳐는 항상 **새 탭**으로 추가하며 기존 캡쳐와 편집 내용은 유지한다.
- **AI 도구 제외**: 최종 확정 UI에는 **AI 도구 버튼·메뉴·자동 설명 기능을 포함하지 않는다**. 향후 도입은 별도 의사결정으로 취급한다.
- **Windows Store 준비**: 키보드 접근성, 고DPI, 다중 모니터, 창 크기 변화, 패키징·업데이트를 고려한다.

## 2. 화면 계층 (기본 상단형)

다음 순서를 **변경하지 않는다**.

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [DIMPIK 로고] 딤픽 DIMPIK                     [캡쳐 기록] [설정] [도움말] ─ □ × │ ① 앱 헤더
├─────────────────────────────────────────────────────────────────────────────┤
│ [새 캡쳐 ▾]  열기  저장  복사  실행 취소  다시 실행                         │ ② 기본 명령
├─────────────────────────────────────────────────────────────────────────────┤
│ [선택] [화살표 ▾] [도형 ▾] [펜 ▾] [형광펜 ▾] [텍스트 ▾] [번호 ▾]           │
│ [모자이크 ▾] [블러 ▾] [자르기] [크기 조절] [영역 복사] [더보기]             │ ③ 편집 도구
├─────────────────────────────────────────────────────────────────────────────┤
│ [▣ 캡쳐 1 * ×] [▣ 캡쳐 2 ×] [▣ 문서화면.png ×] [+]       [탭 목록 ▾]         │ ④ 문서 탭
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│                         (편집 캔버스 / 이미지)                               │ ⑤ 캔버스
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ 937 × 606 px │ PNG │ 저장 상태/캡쳐 시각                 [맞춤] [-] 100% [+] │ ⑥ 상태 표시
└─────────────────────────────────────────────────────────────────────────────┘
```

**중요:** 팝업 설정은 도구 버튼의 아래쪽에 **겹쳐 표시**할 뿐, 탭 아래에 별도 줄을 만들지 않는다. `설정`(앱 환경설정)은 헤더 우측에만 표시한다.

### 2.1 앱 헤더

- 로고, 앱명 `DIMPIK`, 선택적으로 버전 표기.
- 우측 `캡쳐 기록`, `설정`, `도움말`, Windows 창 제어.
- 시각적으로 간결하게 유지. 불필요한 광고·홍보 문구 금지.

### 2.2 기본 명령 영역

- `새 캡쳐`를 가장 강조하는 기본 버튼으로 지정. ▼ 메뉴에서 영역/전체 화면/창 캡쳐 선택.
- `열기`, `저장`, `복사`, `실행 취소`, `다시 실행`을 빠르게 접근할 수 있도록 배치.
- `모두 저장`은 폭에 여유가 있으면 표시하거나 파일/더보기 메뉴에 넣는다.
- 실행할 수 없는 명령은 비활성화 상태로 명확히 표시한다.

### 2.3 편집 도구 영역

- 우선 그룹: **주석**(선택·화살표·도형·펜·형광펜·텍스트·번호), **효과**(모자이크·블러), **이미지 편집**(자르기·크기 조절), **출력/복사**(영역 복사·클립보드), **더보기**.
- 긴 리본의 복제 대신 간결한 그룹 간격·구분선으로 시각적 계층을 만든다.
- 아이콘 스타일·두께·색상·라벨 규칙을 통일한다. 단순 기능용 아이콘은 사용권이 명확한 자체 제작/호환 라이선스 리소스를 사용한다.

## 3. 상단형 / 좌측형 도구 배치

| 항목 | 상단형 (기본) | 좌측형 (선택) |
|---|---|---|
| 기본 명령 | 상단 유지 | 상단 유지 |
| 편집 도구 | 기본 명령 아래 가로 정렬 | 캔버스 왼쪽 좁은 세로 도구 모음 |
| 탭 | 편집 도구 아래 | 기본 명령 아래, 캔버스 위 |
| 속성 팝업 | 도구 버튼 바로 아래 | 도구 버튼 옆, 캔버스를 과도하게 가리지 않는 쪽 |
| 사용 기능 | 동일 | 동일 |
| 설정 위치 | 설정 > 화면 구성 > 도구 모음 위치 | 동일 |

좌측형을 선택해도 **우측 속성 패널은 만들지 않는다**. UI 배치 설정은 사용자 프로필에 저장하고 앱 재시작 후에도 유지한다.

## 4. 도구별 팝업(Flyout) — 핵심 개선

### 4.1 동작 규칙

1. 도구 버튼 **본체 클릭**: 해당 도구 활성화.
2. 도구 버튼 **▼ 클릭**: 연결된 속성 팝업 열기.
3. 팝업에서 색상·굵기 등을 변경하면 이후 그리는 객체에 즉시 적용.
4. 이미지 위 기존 객체를 선택하고 속성을 수정할 경우 **그 객체에만 반영**하며, 이 변경을 실행 취소할 수 있어야 한다.
5. 팝업 바깥 클릭 또는 `Esc`: 팝업 닫기. 편집 내용은 유지.
6. 도구별 마지막 사용 설정을 기억한다. 새 문서에도 도구 기본값으로 이어지게 하되 문서 내 기존 객체에는 소급 적용하지 않는다.
7. 팝업은 **탭/캔버스의 위치나 크기를 변경하지 않는다**.
8. 팝업이 화면 밖으로 넘치면 자동으로 반대 방향에 배치한다.

### 4.2 도구별 최소 속성

| 도구 | 팝업 속성 | 비고 |
|---|---|---|
| 선택 | 별도 팝업 없음 | 선택 객체에서 우클릭 메뉴: 복제·삭제·앞/뒤 순서 등 |
| 화살표 | 색상, 두께, 시작/끝 화살촉 | 선택된 화살표에도 적용 |
| 도형 | 모양(사각형·원·선·화살표·삼각형 등), 테두리 색, 두께, 채우기 | 알캡처의 간편함은 참고하되 디자인은 DIMPIK 고유 스타일 |
| 펜 | 색상, 굵기 | 연속 스트로크 |
| 형광펜 | 색상, 굵기, 불투명도 | 기본 반투명 |
| 텍스트 | 글꼴, 크기, 색상, 굵게/정렬(필요 시) | 텍스트 직접 수정 가능 |
| 번호 | 원형/사각형 등 번호 모양, 색, 크기 | 번호 자동 증가·수동 수정 |
| 모자이크 | 블록 크기/강도 | 영역 지정 후 적용 |
| 블러 | 반경/강도 | 영역 지정 후 적용 |
| 자르기 | 자르기 적용/취소, 비율 프리셋 | 별도 대형 속성 영역 불필요 |
| 크기 조절 | 픽셀/비율, 종횡비 잠금 | 작은 모달/팝업 허용 |

**팝업 권장 기본 폭:** 콘텐츠에 맞춰 약 240~320 DIP. 이 값은 구현 시작점이며 실제 접근성·현지화 테스트 후 조정한다.

### 4.3 색상 선택

- 팝업 내부에 최근 색상과 기본 컬러 스와치를 표시.
- `사용자 지정 색상` 클릭 시 HEX/RGB 입력 가능한 2차 색상 선택기 호출.
- 색상 선택 시 팝업 전체를 반복해서 열고 닫을 필요가 없도록 디자인.
- 마지막 사용 색상은 도구별로 기억.

## 5. 문서 탭 동작

### 5.1 새 캡쳐

- 캡쳐 완료 → 원본 이미지 수신 → **새 문서 탭 생성 → 새 탭 활성화**.
- 기존 탭은 닫거나 덮어쓰지 않는다.
- `+` 탭 버튼은 **새 캡쳐**를 시작한다. 파일 열기는 별도 명령.
- 파일 열기 역시 새 탭에서 처리한다.

### 5.2 탭 표현

- 각 탭: 작은 미리보기(성능 허용 시), 문서명, 수정 표시 `*`, 닫기 `×`.
- 미저장 탭 기본명 `캡쳐 1`, `캡쳐 2` ...; 저장 후 파일명으로 표시.
- 탭 드래그 재정렬 지원.
- 탭 수가 많아지면 탭을 지나치게 작게 압축하지 않고 스크롤/탭 목록 메뉴 제공.
- 활성 탭은 명확한 시각적 표시. 탭 간 전환에서 편집 상태·확대율·선택 상태를 정책에 따라 보존.

### 5.3 닫기 / 저장

- 미저장 편집 내용이 있는 탭 닫기: `저장 / 저장하지 않음 / 취소`.
- 여러 탭을 한 번에 닫을 때는 저장 확인을 중복으로 남발하지 않는 통합 확인 UI 고려.
- `모두 저장`은 저장된 경로가 없는 문서에 대해 파일 이름·경로 선택 정책이 필요.
- 탭 독립 실행 취소/다시 실행 기록 유지.
- **충돌·오작동 시 데이터 보호**: 미저장 작업의 복구 방법을 구현; 자동 복구 파일의 개인정보 보관 정책 명시.

### 5.4 메모리 관리

- 탭별 원본과 주석 객체/편집 이력 분리.
- 비활성 탭은 캐시 절약, 썸네일과 렌더링 캐시 크기 제한.
- 사용자가 열어 둔 탭을 임의로 닫지 않는다.
- 다수의 4K 캡쳐 시 메모리 급증이 없는지 테스트.

## 6. 캔버스·상태바

- 캔버스는 좌우에 **고정 도구/속성 사이드바 없이 최대 폭**으로 제공.
- 기본 표시: 새 이미지 `화면에 맞춤`을 우선 고려하되 업스케일 과도 여부를 검증; 확대 배율은 명확하게 표시.
- 휠 확대 정책·커서 중심 확대·손 도구/스페이스 드래그 등 이동 동작 일관성 확보.
- 실제 이미지 원본과 화면 표시 좌표를 분리하여 DPI 변화·줌·스크롤에서도 주석 위치가 어긋나지 않아야 함.
- 필요시 눈금자는 보기 메뉴에서 켜기/끄기. 기본 UI에 상시 강제하지 않음.
- 하단 상태바: 이미지 픽셀 크기, 파일 포맷, 저장/수정 여부 또는 캡쳐 시각, 맞춤, 줌 아웃, 배율, 줌 인.
- 선택하지 않은 상황에서 이미지 전체 테두리에 불필요한 선택 핸들을 항상 보여주지 않음.

## 7. 반응형 도구 모음

그림판처럼 **기능이 폭에 따라 줄어드는 동작**만 참고하고 외형은 DIMPIK 고유 디자인으로 한다.

| 상태 | 기대 동작 |
|---|---|
| 넓은 창 | 주요 아이콘 + 한글 라벨, 대부분 도구 직접 노출 |
| 중간 창 | 일부 보조 라벨 제거, 도구 그룹 단위 축약 |
| 좁은 창 | 우선순위 높은 기능 유지, 나머지는 `더보기`로 이동 |

- 고정된 단일 픽셀 경계만 사용하기보다 도구 그룹의 실제 필요 폭을 기준으로 축약.
- 새 캡쳐, 저장, 활성 도구, 탭 접근은 좁은 창에서도 쉽게 사용 가능해야 함.
- 메뉴가 창 밖으로 잘리지 않게 처리; 최소 창 크기를 정의.
- Windows 텍스트 배율 125%·150%·200%에서 라벨 잘림과 접근성 검증.

## 8. 캡쳐 기능·편집 안정성

### 8.1 필수 캡쳐

- 영역 캡쳐, 전체 화면, 특정 창 캡쳐.
- 다중 모니터(서로 다른 DPI/배율, 음수 화면 좌표 포함)에서 정확한 위치·크기.
- 전역 단축키 등록/충돌 검증 및 사용자가 변경 가능하게 설계.
- 캡쳐 오버레이에서 `Esc` 취소, 마우스 드래그 영역 표시, 모니터 경계 처리.
- 이미지 캡쳐 실패 시 원인/재시도 경로 제공; 이전 작업 상태 손실 금지.

### 8.2 편집 정확성

- 주석은 가능하면 **비파괴적 객체 레이어**로 유지하여 나중에 다시 선택·이동·편집 가능하게 설계.
- 저장/내보내기 시 원본+주석 합성. 원본을 덮어쓰는 경우 명확한 사용자 의사 확인.
- 모자이크/블러 효과의 미리보기와 최종 저장 결과 일치.
- PNG 중심, JPEG 등은 필요에 따라 제공.
- 복사 시 주석이 포함된 최종 이미지를 클립보드에 복사할지 원본만 복사할지 명확히 분리.
- 실행 취소/다시 실행은 객체 추가·삭제·이동·속성변경·효과 적용에 일관되게 적용.

## 9. 캡쳐 기록과 개인정보

- 상단 `캡쳐 기록` 버튼으로 이전 캡쳐 썸네일 목록을 **요청 시에만 팝업**으로 표시.
- 기록은 현재 열린 탭과 구분: 탭=현재 편집 문서, 기록=이전 캡쳐 접근.
- 자동 기록 저장 여부·보관 기간·모두 지우기·저장 폴더 설정 제공.
- 캡쳐에는 자격증명·개인정보가 포함될 수 있으므로 무단 클라우드 업로드 금지.
- 이 버전에서는 **AI 기능·AI 업로드·AI API 설정을 포함하지 않음**.

## 10. 시각 디자인 및 자산

- Windows 사용자가 익숙한 사용성은 유지하되 **알캡처와 동일한 아이콘 순서·버튼 비율·툴바 묶음·팝업 외형을 복제하지 않는다**.
- DIMPIK 로고는 이전에 선택한 **캡쳐 영역/커서 정체성이 분명한 초기 로고 방향**을 기반으로 하되 최종 파일 적용 전 유사 로고 및 권리 검증 필요.
- 외부 유료 아이콘·유료 폰트·유료 UI 에셋을 무단 사용하지 않음. 생성 이미지라고 법적 무충돌이 보장되는 것은 아님.
- 밝은 모드 우선, 다크 모드 추가 가능하도록 디자인 토큰 기반 설계.
- 간격·모서리·아이콘 스트로크·호버·포커스·선택 상태를 디자인 시스템으로 통일.
- Microsoft Store용 앱 아이콘은 별도 고해상도 원본에서 필요한 크기로 출력.

## 11. 구현 권장 구조

> 권장안이며 기존 코드베이스를 검토한 뒤 마이그레이션 범위를 확정한다. **UI 개선을 위해 안정적인 캡쳐 엔진을 무조건 재작성하지 않는다.**

- **UI 후보:** C# + WinUI 3 + Windows App SDK. 기존 프로젝트가 WPF/WinForms라면 현재 구조·성능과 이식 비용을 비교 후 결정.
- **공통 모듈:** `Dimpik.Core`(문서/주석/Undo), `Dimpik.Capture`(캡쳐 API), `Dimpik.Imaging`(이미지 처리), `Dimpik.App`(UI), `Dimpik.Package`(배포).
- **UI 분리:** `MainCommandBar`, `AdaptiveToolBar`, `ToolOptionsFlyout`, `CaptureTabStrip`, `EditorCanvas`, `StatusBar`, `CaptureHistoryFlyout`.
- **데이터:** 탭 하나당 고유 Document ID / 원본 이미지 / 주석 객체 / 저장 경로 / 수정 여부 / 확대 배율 / 편집 이력.
- **스토어:** MSIX 패키징 및 Microsoft Store 심사·기능 선언·권한·업데이트 정책 점검. GitHub Releases 배포도 별도 지원 가능.

## 12. 개발 우선순위

### P0 — 첫 UI 개선 릴리스 필수

1. 브랜드명 DIMPIK 적용, AI 도구 제거.
2. 헤더 → 기본 명령 → 도구 → 탭 → 캔버스 → 상태바 순서 구현.
3. 도구별 SplitButton + Flyout 설정, 별도 속성 바 제거.
4. 새 캡쳐마다 새 탭 추가, 저장 표시, 탭 전환/닫기/저장 보호.
5. 좌우 고정 패널 없는 캔버스.
6. 창 너비에 따른 도구 축약 및 `더보기`.
7. 캡쳐·저장·기존 편집 기능 회귀 테스트.

### P1 — 사용성 향상

1. 상단/좌측 도구 위치 설정 및 유지.
2. 탭 재정렬·탭 목록·모두 저장.
3. 캡쳐 기록 팝업 및 기록 보관 설정.
4. 도구별 최근 설정 기억, 단축키 사용자 설정.
5. 다중 모니터·고DPI·고배율 테스트.

### P2 — 확장

1. 세션 복구 고도화와 대용량 탭 메모리 최적화.
2. 다크 모드, 접근성 정교화.
3. 고급 캡쳐(스크롤 캡쳐 등)는 안정성 검증 후 독립 릴리스.
4. AI 기능은 현재 범위 밖. 추후 별도 기획/동의 절차 후 평가.

## 13. 완료 기준 (Acceptance Criteria)

- [ ] AI 도구 버튼·메뉴가 최종 기본 UI에 없다.
- [ ] 기본 상단형에서 **도구 모음이 탭보다 위**에 있다.
- [ ] 도구 속성을 열어도 별도 속성 행이 추가되지 않고, 탭·캔버스가 움직이지 않는다.
- [ ] 도구 버튼 본체/▼ 클릭 역할이 명확하게 분리되어 있다.
- [ ] 도형 팝업에서 모양·색상·두께·채우기를 바꿀 수 있다.
- [ ] 캡쳐를 연속 5회 하면 기존 탭을 유지하면서 탭 5개가 생성된다.
- [ ] 다른 탭에서 편집 중인 내용이 탭 전환으로 소실되지 않는다.
- [ ] 미저장 탭을 닫을 때 저장 확인이 동작한다.
- [ ] 좁은 창에서 도구가 화면 밖으로 사라지지 않고 더보기 등으로 접근 가능하다.
- [ ] 상단형/좌측형 전환 후 기능 차이가 없고 재시작 시 사용자 선택이 유지된다.
- [ ] 캡쳐 이미지의 좌우에 고정 속성 패널이 기본적으로 존재하지 않는다.
- [ ] 복잡한 다중 모니터·DPI 상황에서 캡쳐 좌표와 편집 객체 좌표가 일치한다.
- [ ] 저장된 이미지와 화면 미리보기에서 주석 위치/두께/색상이 일치한다.
- [ ] Microsoft Store 배포 준비용 패키징 및 라이선스/자산 점검 항목을 충족한다.

## 14. 구현 시 하지 말 것 (명시적 금지)

- 알캡처/그림판 화면이나 도구 순서를 그대로 복제하지 않는다.
- 우측에 상시 노출되는 속성 패널을 다시 추가하지 않는다.
- 탭 아래에 속성 설정 줄을 추가하지 않는다.
- 도구 선택 때문에 편집 캔버스가 출렁이거나 이동하지 않게 한다.
- 새 캡쳐가 기존 탭 문서를 덮어쓰지 않게 한다.
- AI 도구를 최종 UI에 임의로 다시 넣지 않는다.
- 기존 편집 중인 내용을 UI 변경·캡쳐 오류·탭 조작으로 잃지 않게 한다.
